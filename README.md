# article_recognizer
Recognize credibility of short articles.

# Data
Train data was generated by gemini 2.5 pro with prompt:
"Generate 100 examples of short articles in english in JSON format.
50 credible (label=1) and 50 non-credible (label=0). Each object: {title, text, label}. For unreliable articles: clickbait, emotional tone, lack of sources. For reliable articles: neutral tone, data, quotes. Articles should consist of 2/3 complete sentences. Topics: politics, health, technology, economics. Respond ONLY in JSON, without markdown."

Mock test data was generated by Claude Sonnet 4.6 (I used different model to avoid data leakage).

Real test data was copied from reuters.com for credible articles and the-sun.com for fake articles.

# Usage
For multi-article recognision:
python3 article_recognizer.py --json path-to-json-files-with-articles

or
For single recognision:
python3 article_recognizer.py --title "article title" --text "article text"
