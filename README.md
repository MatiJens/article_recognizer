# Article Recognizer

> Recognize the credibility of short articles using machine learning.

---

## Overview

**Article Recognizer** is a tool that classifies short news articles as either **credible** or **fake**. It analyzes textual features such as tone, use of sources, and emotional language to distinguish between reliable journalism and misleading content.

---

## Data

### Training Data

Training data was generated by **Gemini 2.5 Pro** using the following prompt:

> *"Generate 100 examples of short articles in English in JSON format. 50 credible (label=1) and 50 non-credible (label=0). Each object: `{title, text, label}`. For unreliable articles: clickbait, emotional tone, lack of sources. For reliable articles: neutral tone, data, quotes. Articles should consist of 2/3 complete sentences. Topics: politics, health, technology, economics. Respond ONLY in JSON, without markdown."*

### Test Data

- **Mock test data** — generated by **Claude Sonnet 4.6** (a different model was used to avoid data leakage).
- **Real test data** — collected from real sources:
  - Credible articles: [reuters.com](https://www.reuters.com)
  - Fake articles: [the-sun.com](https://www.the-sun.com)

## Usage

### Multi-article recognition

Classify multiple articles from a JSON file:

```bash
python3 article_recognizer.py --json path-to-json-files-with-articles
```

### Single article recognition

Classify a single article directly from the command line:

```bash
python3 article_recognizer.py --title "article title" --text "article text"
```
